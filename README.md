## 🌟 主项目:FOJ 在线判题系统

一个基于 **Spring Cloud Alibaba + RabbitMQ + Docker 沙箱 + 大模型 API** 的编程评测平台,
四个仓库联动,覆盖网关路由、异步判题、代码隔离执行、AI 题解全链路:

| 模块 | 仓库 |
|---|---|
| 🧩 微服务后端(网关 + 三服务) | [foj-backend-microservice](https://github.com/Hob-F/foj-backend-microservice) |
| 🎨 Vue3 前端 | [foj-frontend](https://github.com/Hob-F/foj-frontend) |
| 📦 代码沙箱(独立部署) | [foj-code-sandbox](https://github.com/Hob-F/foj-code-sandbox) |
| 🤖 AI 智能题解服务 | [foj-ai-service](https://github.com/Hob-F/foj-ai-service) |

👉 **从 [foj-backend-microservice](https://github.com/Hob-F/foj-backend-microservice) 的 README 进入,可看到完整架构图与启动顺序。**
